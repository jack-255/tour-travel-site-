# Tiwua Tours & Safaris Website

A responsive static tour and safari website created for the "jacks website" workspace.

## Files

- `index.html` — Website homepage
- `styles.css` — Styling for layout, colors, and responsive behavior
- `script.js` — Mobile navigation toggle and form interaction

## Usage

1. Open `index.html` in a browser.
2. Optionally serve the folder with a static server.

Example using Python:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
